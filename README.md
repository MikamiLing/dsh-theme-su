# 祀 · dsh-theme-su

 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 的水墨主题，部分样式全部可调。

设计语言参考了社区里的「特蕾西娅」主题。

素材版权归原画作者，见 [LICENSE](LICENSE)）：


![祀 · 界面](docs/screenshot-light.png)

![设置界面与 Q 版吉祥物](docs/screenshot-settings.png)

大家可以根据设置自行调节，各界面的样式透明度。

## 安装

从 GitHub 装（推荐，无需先克隆）：

```bash
dsh plugin --profile <profile> add github:MikamiLing/dsh-theme-su
```
