祀 · dsh-theme-su  v0.0.2  ——  手动安装说明
==================================================

这个压缩包是一个完整的 DeepSeek Harness 主题插件，素材已内置，
不需要额外的图片文件，也不需要联网安装依赖（零运行时依赖、无构建步骤）。
v0.0.2 起还包含开屏动画：默认播放内置短片，可在设置里换成自己的视频/动图。


一、解压
--------
把压缩包解压到任意固定目录，例如：

    D:\dsh-theme-su

解压后该目录里应该有：index.js、splash.js、client.js、cordis.patch.yml、
package.json、assets\、tools\、README.md。请让这个目录保持不动，
后面 profile 用绝对路径指向它。


二、找到你的 profile 目录
------------------------
DSH 的用户目录默认是：

    %USERPROFILE%\.dsh          （即 C:\Users\<你的用户名>\.dsh）

profile 在它下面的 profiles\ 里，常见两个：

    ...\.dsh\profiles\desktop   ← DeepSeek Harness 桌面版用的就是这个
    ...\.dsh\profiles\web       ← 命令行 dsh web 用的

不确定用哪个？打开 DSH 桌面版，用任务管理器看进程命令行里带
profiles\desktop 还是 profiles\web，或者干脆两个都装（互不影响）。


三、改 profile 的 package.json
------------------------------
用记事本/VS Code 打开该目录下的 package.json，改成这样
（保留你原有的其它依赖和 bundles，只加 dsh-theme-su 这一项）：

{
  "name": "dsh-profile-desktop",
  "private": true,
  "dependencies": {
    "dsh-theme-su": "link:D:\\dsh-theme-su"
  },
  "dsh": {
    "profile": {
      "bundles": [
        "@deepseek-ai/dsh-base",
        "@deepseek-ai/dsh-web-app",
        "dsh-theme-su"
      ]
    }
  }
}

注意：
  * dependencies 里写的是你第一步的解压路径，反斜杠要写成两个 \\
  * bundles 里必须同时加上 "dsh-theme-su"，否则插件不会被加载
  * 保存时用 UTF-8，不要存成 ANSI


四、安装（把 link 依赖落到 node_modules）
----------------------------------------
在该 profile 目录里执行一次 pnpm install。DSH 桌面版自带 pnpm，
路径形如：

    "<DSH安装目录>\resources\runtime\primary-runtime\dependencies\node\bin\node.exe" ^
    "<DSH安装目录>\resources\runtime\primary-runtime\dependencies\pnpm\bin\pnpm.mjs" install

也可以直接用系统里的 pnpm：

    cd %USERPROFILE%\.dsh\profiles\desktop
    pnpm install

成功的话会看到一行：+ dsh-theme-su 0.0.2 <- D:\dsh-theme-su


五、重启 DSH
------------
完全退出 DeepSeek Harness（托盘里也要退出），再重新打开。


六、确认生效
------------
  * 启动后界面应该是象牙白纸色 + 水墨长卷背景
  * 侧栏底部站着角色立绘（切换对话会换一张）
  * 设置 → 内置插件 → 「祀」 里有全部参数（含「开屏动画」一节）
  * 设置界面左下角会出现 Q 版吉祥物
  * 刷新页面或重开 DSH 时会先播开屏短片；不想要就关「启用开屏动画」


七、常见问题
------------
1) 界面没变化
   - 检查 bundles 里是否加了 "dsh-theme-su"
   - 检查 pnpm install 是否成功、node_modules\dsh-theme-su 是否存在
   - 确认是改的「正在使用」的那个 profile

2) 启动黑屏 / 报插件加载失败
   - 多半是 package.json 存成了 ANSI 或 JSON 语法错了（多/少逗号）
   - 把 package.json 改成合法的 JSON 再重启

3) 想换回默认外观
   - 设置 → 内置插件 → 祀 → 关闭「启用主题」
   - 或把 bundles / dependencies 里的 "dsh-theme-su" 删掉，重跑 pnpm install

4) 想彻底删除
   - 删掉 profile 的 node_modules\dsh-theme-su 软链、package.json 里的两处条目
   - 以及 %USERPROFILE%\.dsh\dsh-theme-su\ （保存的配置）
